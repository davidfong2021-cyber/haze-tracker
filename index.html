PSI bands

  • 0–50 Good
  • 51–100 Moderate
  • 101–200 Unhealthy
  • 201–300 Very unhealthy
  • 301+ Hazardous

The 24-hr PSI is NEA's official reading. NEA does not publish a 1-hr PSI, so the 1-hr PSI shown here is estimated from NEA's 1-hr PM2.5 reading using the PSI PM2.5 breakpoints. It is a guide only.
